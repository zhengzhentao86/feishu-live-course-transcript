# 使用指引

## 第一次使用：环境准备

首次安装、换电脑或出现 lark-cli 错误时，先运行：

```bash
ruby scripts/preflight.rb
```

脚本会区分：缺少 lark-cli、缺少 npm、缺少 Swift、未配置、未登录、缺少权限和环境就绪。它默认只检查，不安装、不登录、不读取飞书课程数据。

- 缺少 lark-cli：先告诉用户将从国内 npm 镜像下载 `@larksuite/cli` 并写入 `~/.local`。只有用户明确同意后运行 `ruby scripts/preflight.rb --install-lark-cli --yes`；禁止使用 sudo。
- 缺少 npm：提示先安装 Node.js；如需代装，必须另行取得用户同意。
- 缺少 Swift：提示安装 Xcode Command Line Tools；未安装前不能运行本地 Vision OCR。
- 未配置：运行 `lark-cli config init --new`，按命令输出展示配置链接和二维码。
- 未登录或缺少权限：只申请脚本列出的最小 scope。必须使用 `--no-wait --json`，把原始授权链接和二维码展示给用户；用户确认后再完成 device-code 交换。
- `action=ready`：使用输出的 `LARK_CLI_BIN` 继续。安装路径不在 PATH 时，运行后续脚本前设置同名环境变量。

安装、配置和授权完成后重新运行预检。只有 `action=ready` 才进入建群解析、会议解析和文档创建；普通五分钟增量轮次不重复预检。

## 最省事的开课流程

1. 建飞书群。
2. 开飞书会议并开启实时转写。
3. 调用 Skill，只需提供课程名、群名、讲师名；Skill 自动解析群和当前会议、检查实时字幕，并默认创建新文档。
4. 上课时把 PPT 按顺序拍进群。
5. 课程结束后等待自动收尾，或说“课程结束”。实时工作稿用于边上课边看；最终会另建一份按主题分章的正式成品稿。

默认每堂课新建文档。如果用户没有明确说“追加到旧文档”，不要复用上次的文档 token。

## 每次调用固定开场

无论是开始新课、恢复课程还是手动收尾，都先用一句“本次使用指引”告诉用户：

- PPT 发到哪个群；
- 飞书会议和实时转写需要保持开启；
- 每条新图片消息都会保留，不做同页相似度去重；
- 本次默认新建文档或正在续写哪份文档；
- 没有新增图片时，新产生的会议转写仍会直接写入。
- 整理方式是忠实精修：删口水词但保留解释、例子和原讲解顺序，不压缩成摘要。

随后直接执行可解析的步骤，不反复让用户确认已经明确的参数。

每堂新课首次写云端前必须列明：将把课程群 PPT、会议或妙记转写、讲师姓名写入新的飞书云文档，并排除无关群消息、密钥和本地私人资料。用户明确确认后，把 consent 记录到状态中；同一会话恢复和自动增量不重复确认。

## 支持的调用形式

- 只给群名：从当前账号可见群中解析，重名时再询问。
- 给 `chat_id`：直接使用。
- 只说“当前会议”：从进行中的会议解析，多个会议时再询问。
- 给会议 ID：直接使用。
- 没给讲师名：可从会议主题和参与者推断候选，但写入前必须得到可靠映射；不能把拍摄者误写成讲师。
- 用户给旧文档链接并明确要求追加：解析 token，记录当前 revision，再创建新章节或使用用户指定章节。

## 自动任务建议

- 检查间隔：默认 2 分钟；单次云端 batch 覆盖 2–6 分钟内容；
- 图片处理缓冲：30 秒，用于等待会议转写上下文，不用于去重；
- 会议结束后等待：10 分钟，用于接收最后的照片；
- 没有新图但有新转写：追加纯文本增量块；
- 图片与转写都没有新增：静默；
- 群消息关闭 reactions 补查，只取 `last_message_scan_end` 之后的窄窗口（旧状态回退 `last_message_time`），并用 `last_message_position` 本地过滤；完整成功后才推进扫描边界；
- 会议事件优先复用 `meeting_event_page_token`，否则只取 `last_transcript_end_time` 后的窄窗口；
- 第一轮从课程开始时间建立群图片全量基线；之后每轮只下载和 OCR 新图片；摄影者为空时不限制发送人；
- 本轮全部内容合成一个 batch，一次写入、一次尾部局部回读；
- 课中不读取正式妙记、不做整章验收和首中尾预览；
- 正式妙记校正只在整门课结束后执行一次；发现历史缺口时重建 canonical groups，不在工作文档尾部追加补丁；
- 恢复旧会话时先升级到 v5；若没有尾部锚点或迁移发现时间倒退，先处理重建，不能混入两分钟轮询；
- revision 漂移：停写并保留现场文件；
- 最终从 canonical groups 生成“阅读说明 + 主题章节 + 连续课程时间 + 逐字稿 + PPT”的新成品文档；实际查看首中尾三张图片后才允许验收通过并停止自动任务。
