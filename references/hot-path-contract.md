# 热路径简约合同

普通轮次每 2 分钟只做：增量采集 → 路由 → compact context → 轻度精修/对齐 → 确定性 batch → 忠实度检查 → 一次写入和一次尾部回读。

模型输入只含本批转写、新图 OCR 与时间、上一批最后两段、讲师映射、revision 和六条简版质量规则。不要读取其他 reference。

连续多图先按 OCR 与转写句意拆成多个“一段相关讲解 + 一张图”的单图组，不能因发送时间接近就机械合并，也不能复制同一段正文。只有同页重拍、总览页组或共享讲解不可可靠拆分时，才输出带 `alignment_reason` 的 `image_group`，并以最多四列栅格并排。未绑定图片的新增转写必须成为纯文本条目。每段 ≤230 字，内容多就拆段。source_text 保留率 ≥80%，正文原文顺序依据 ≥75%。

零增量只用 `commit_empty_poll.rb` 推进本地扫描游标，不调用模型或云文档；只有图片没有字幕时 `wait`，不推进游标。revision/结构错误立即停止；历史缺口或课程时间早于尾部时 `rebuild`，禁止追加“补全”章节。第一轮从课程开始时间建立全量图片基线，之后课中不重查历史图片、不读妙记、不全文回读。
